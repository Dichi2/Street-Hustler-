STREET HUSTLE — ALL-IN-ONE TEST BUILD

This is a playable browser prototype combining the major planned systems:
account/profile placeholder, 3 starting cities, SC, jobs, levels/rewards, player/business worth,
properties, vehicles, game buyback, negotiation/counteroffer, installment-ready contract structure,
NPC workers, player employment, Game Court simulator, Street Exchange, travel, leaderboard,
reputation and local save/export.

IMPORTANT: It is a prototype. Real online accounts, cloud saves, multiplayer, server-side escrow,
anti-cheat, secure Game Court evidence, real Google Play Billing, and production backend are not
implemented in this single-file test build.
